- Hazır HTML silinip tekrar oluşturulmuyor; React aynı düğümlere etkileşimleri bağlıyor. 80 rota/cihaz kontrolünde H1 korundu ve hydration kurtarma hatası görülmedi.
- 16 menü kontrolü ve sekiz teklif formu hizmet seçimi/alan koruma kontrolü geçti; gerçek talep veya e-posta gönderilmedi.
- Font kaynaklı geç değişimler sınırlandı; Türkçe/Latin karakter kapsamı tamamlandı ve sürümlü font dosyaları üretildi. Yavaş ilk bağlantıda sistem fontu korunabilir.
- Mobil boyut belirlenmeden büyük hero görselini indiren preload sırası düzeltildi; dışa aktarma için gereken JavaScript ziyaretçi ön yüklemesinden çıkarıldı.
- Sayfa verisi yalnızca açılan rotayla sınırlandı; aynı verinin ikinci kopyası azaltıldı. Bildirim bileşenleri ihtiyaç duymayan ana sayfalarda yüklenmiyor.
- İlk gerçek çizimden sonra etkileşim kodu bağlanıyor; kullanıcı girdisi beklemeyi anında sonlandırıyor. Test motoruna özel davranış yok.
- 48 marka/tema/ekran gezinme kontrolü başarılı; hizmet bağlantıları, Escape, mobil menü ve yatay taşma sınandı.
- 99 uygulama + 46 Node testi, TypeScript ve kaynakla eşleşen kalite CI kontrolü başarılı.
- 80 rota/cihaz hücresinin 72 tanesi medyan LCP ≤ 2,5 sn, CLS ≤ 0,1 ve TBT ≤ 200 ms laboratuvar eşiklerini birlikte sağlıyor. TBT, gerçek kullanıcı INP ölçümü değildir.
