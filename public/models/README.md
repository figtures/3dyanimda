# Original showcase geometry

Nine project-owned illustrative GLB assets generated by
`scripts/generate-showcase-models.mjs` using Three.js GLTFExporter.

- Industrial/product development: fixture, impeller, enclosure.
- Architecture: campus, villa, district.
- Replacement/connection parts: duct, clip, knob.

No external third-party models or customer designs are included. These files
illustrate service categories, not tested, dimensioned or print-ready products.
Do not represent them as commissioned customer work. Regenerate with:

    node scripts/generate-showcase-models.mjs

Meshes use reusable geometry and PBR materials. Runtime viewers load assets near
the viewport, render only on changes, support touch/keyboard rotation and offer
zoom/reset. The quote engine remains independent and accepts customers' STL/CAD
files through its existing workflow.
